# 书签进入操作页自动跳转

- 入口：普通场景顶部“编辑书签”列表内新增 MaterialSwitch，“进入操作页自动跳转到最后添加的书签”。没有书签时也可以打开此设置。
- 全局独立偏好 `DumbEditBookmarks/auto_jump_enabled`，默认开启；对每个场景只使用该场景的书签。
- 最后一个指书签数组最后一项，即最后添加的书签；重命名/重新绑定不改变顺序，删除最后一项后使用当前数组最后一项。
- `BookmarkEntryJump` 等待书签加载和 ListAdapter 提交完成，每次进入页面仅消耗一次跳转；后续动作编辑、列表刷新和书签变更不会反复抢占滚动位置。
- 页面停止时重置入口状态；回到页面重新加载后允许再次跳转。手动打开动作编辑弹窗未停止内容页时，不重复跳转。旋转重建新内容页后可重新定位。
- 同一 `pendingJump / performPendingJump` 路径执行自动/手动跳转：RecyclerView post、按动作稳定 ID 找到位置、下一次 layout 后高亮 1.8 秒。
- 目标不存在时使用现有失效提示，绝不改用相邻动作；无书签时不滚动。
- 开关关闭后保留手动跳转；不修改场景动作或执行引擎。

新增 5 项自动验证：两种加载完成顺序、同一次进入仅跳一次及重入、关闭/空书签不在后续更新抢滚动、最新按添加顺序判定且重命名不改顺序、全局开关跨实例持久化且不修改书签。

运行相关 feature:dumb-config/core:dumb 单测及 assembleFDroidDebug。真实手机上进入长列表后的滚动和开关排版需人工验收。

验证结果：34 项相关单元测试全部通过，FDroidDebug ARM64 APK 构建成功，git diff --check 通过。通过 adb install -r 覆盖安装到手机 c7cbd54b，返回 Success；真实页面滚动与开关排版仍待用户实际验收。
